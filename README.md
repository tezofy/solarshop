# Solar Shop — Homepage Replica (Contest Entry)

100% single-file replica of solarshop.co.nz homepage with an upgraded hero:
5-slide photorealistic slider (residential roof, ground-mount field, commercial
rooftop, battery project, rural farm), blur-glass 5.0 rating badge, brand-colour
social rail, PV-stat panel and energy-story band.

- `index.html` — the entire site (CSS, JS, fonts, images inlined; zero external requests)
- Open `index.html` directly in a browser, or serve the folder as-is.

## Deploy
Cloudflare Pages / GitHub Pages / Netlify: point the build at this folder,
output directory `/`, no build command.

Live demo: https://solarshop-cza.pages.dev/
